# Rock Paper Scissors Game

A simple, interactive **Rock Paper Scissors** game built with Python. Play the classic hand game against the computer, which randomly selects its move. The program compares both choices and determines the result.

## Features

- Play Rock, Paper, or Scissors against the computer.
- Computer moves are selected randomly.
- Automatically determines the winner of each round.
- Simple command-line interface.
- Beginner-friendly Python project.

## Requirements

- Python 3
- No external libraries are required if the program uses only Python's built-in modules.

## How to Run

1. Make sure Python 3 is installed.
2. Save the source code as `main.py`.
3. Open a terminal or command prompt in the folder containing the file.
4. Run:

   
   main.py


   If your system uses the `python3` command, run:

   
   main.py
   

## How to Play

1. Start the program.
2. Enter Rock, Paper, or Scissors when prompted.
3. The computer randomly selects its move.
4. The program compares the two choices and displays the result.

## Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both choices are the same, the round is a tie.
